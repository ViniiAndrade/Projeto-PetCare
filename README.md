# Projeto-PetCare
Landing page responsiva para um negócio de cuidados com pets, feita com HTML, CSS e JavaScript puro. Inclui menu mobile, cards de serviços (produtos, cuidados e gastos com pet), formulário de cadastro de pet com validação e rodapé com contato e redes sociais. Projeto criado a partir de um esboço feito à mão.
